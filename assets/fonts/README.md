# Tipografía

Poppins es la tipografía primaria de Taylor según el brand book.

Descárgala desde [Google Fonts](https://fonts.google.com/specimen/Poppins) y
coloca en esta carpeta exactamente estos cuatro archivos, con estos nombres:

- `Poppins-Regular.ttf`
- `Poppins-Medium.ttf`
- `Poppins-SemiBold.ttf`
- `Poppins-Bold.ttf`

Los nombres deben coincidir con lo declarado en `pubspec.yaml`. Si falta alguno,
Flutter cae silenciosamente en la fuente del sistema y la app pierde su
identidad tipográfica sin dar error.

Poppins se distribuye bajo SIL Open Font License 1.1, que permite uso comercial
e incrustación en aplicaciones.
